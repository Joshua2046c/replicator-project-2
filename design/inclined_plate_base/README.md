# 10° 楔形 iPad 底座

单件 FDM 打印，毛坯宽 180 mm、斜长 110 mm、前端厚 8 mm，顶面坡度 10°，水平底面直接放桌面。

## 端部下沉台面

按 product/references/uploads/20260922T073513764Z-1-mark.png 红框和用户要求，删除原独立圆角矩形盲凹槽，改成窄台面负 X 端整块下沉。名义长度沿 X 为 24 mm，下沉深度沿原顶面法向为 7 mm，沿用原矩形对应尺寸。负 X 端无围边，后侧也敞开，跨后方窄台面的全宽直到 iPad 插槽。其余窄台面不降低。下沉底面与原顶面平行，台阶与外轮廓转角 R3；24 mm 是圆角前台阶位置，不是圆角后的平直底面长度。

旧参数 pocket_width 和 pocket_depth 保留名称，现控制端部下沉长度和深度；原小凹槽的位置、轮廓半径和高度参数已移除。

## iPad 插槽

插槽切割形状不变：两端贯通，沿斜面槽口宽 10 mm、法向深 8 mm、底部前偏 4.6188021535 mm，后仰 20°（桌面夹角 70°）。插槽口、侧端与槽底交界不做倒角或圆角。新台面局部降低端部后侧支承高度，其余区域保持原槽壁。不要把台阶 R3 延伸到对侧大台面或 iPad 插入边缘。

底面周圈保留 0.5 mm 倒角，完整底部不切穿。具体 iPad/保护壳配合、承载和防倾倒仍需实物验证。

## Making and assembly

单件打印。让完整水平底面朝下切片；材料、层高和支撑方案按实际打印机与承载需求确定。

底面外缘倒角仍保留；圆角底部附近的局部悬垂须在切片预览中检查，必要时设置支撑。未生成切片或 G-code。
